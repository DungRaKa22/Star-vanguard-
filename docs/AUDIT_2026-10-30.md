## 2. Điểm mạnh đã kiểm chứng (giữ nguyên, đừng phá)

1. **Singleton có vòng đời đúng**: `Singleton<T>` phân biệt `[SceneBoundSingleton]` (UI, WaveDirector, Parallax) và persistent (GameManager, AudioManager, PoolManager); `SingletonRegistry` reset static trước mỗi lần vào Play Mode → chống lỗi "domain reload disabled" — đây là thứ rất nhiều dự án sinh viên làm sai.
2. **Kiến trúc 3 scene sạch**: `BootstrapScene (index 0) → MainMenuScene → GameplayScene`, manager persistent chỉ sống ở Bootstrap, `BootstrapLoader` hỗ trợ mở scene lẻ trong Editor (`BootstrapLoader.cs:31-47`). Đã kiểm tra `EditorBuildSettings.asset` → thứ tự build đúng.
3. **Serialization toàn vẹn**: 0 GUID trùng, 0 `.meta` mồ côi, 0 asset thiếu `.meta`, 0 component "Missing Script" (49 GUID lạ đều là script của package uGUI/TMP/InputSystem/URP — đã đối chiếu từng cái).
4. **Object pool đúng chuẩn**: `ObjectPool<T>` + `IPoolable` (`OnPoolGet/OnPoolReturn`), `PoolManager` gom 6 pool, có `HasEnoughEnemies()` chống spawn thiếu.
5. **Số liệu REA khớp code**: heat/shot `0.045`, cooling `0.35/s` (`WeaponHeatController.cs:23-26`), `50 crystal = 1 bomb` (`PlayerStats.cs:21,74-83`), boss 3 pha (`BossShooting.cs`).
6. **Có sẵn công cụ nghiệm thu**: `StarVanguardValidator.ValidateAll()` chạy `-batchmode -quit -executeMethod` và `EditorApplication.Exit(failed == 0 ? 0 : 1)` → **đã sẵn sàng làm CI gate**, chỉ thiếu workflow.
