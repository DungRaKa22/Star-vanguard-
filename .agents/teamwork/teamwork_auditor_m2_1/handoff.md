## 1. Observation

### 1.1 Decoupling & Event Architecture Inspection
- **Source Files Inspected**:
  - `Star Vanguard/Assets/Scripts/UIManager.cs` (lines 1–349)
  - `Star Vanguard/Assets/Scripts/UI/UIPanelRouter.cs` (lines 1–336)
- **Observations in `UIManager.cs`**:
  - `using StarVanguard.UI;` was completely removed.
  - Declared 7 genuine static C# events:
    ```csharp
    public static event Action OnShowSettingsRequested;
    public static event Action OnHideSettingsRequested;
    public static event Action OnShowControlsRequested;
    public static event Action OnHideControlsRequested;
    public static event Action OnShowAudioSettingsRequested;
    public static event Action OnHideSubPanelsRequested;
    public static event Action OnHideAllPanelsRequested;
    ```
  - Replaced direct `UIPanelRouter.Instance` calls in public methods with event invocations:
    - `ShowControlsPanel()` invokes `OnShowControlsRequested?.Invoke()`
    - `HideControlsPanel()` invokes `OnHideControlsRequested?.Invoke()` and `OnHideSubPanelsRequested?.Invoke()`
    - `ShowSettingsPanel()` invokes `OnShowSettingsRequested?.Invoke()`
    - `HideSettingsPanel()` invokes `OnHideSettingsRequested?.Invoke()` and `OnHideSubPanelsRequested?.Invoke()`
    - `ShowAudioSettingsPanel()` invokes `OnShowAudioSettingsRequested?.Invoke()`
    - `HideSubPanels()` invokes `OnHideSubPanelsRequested?.Invoke()`
    - `HideAllPanels()` invokes `OnHideAllPanelsRequested?.Invoke()` and flushes scene panels via `hideAllPanels()`
  - Public method signatures were preserved, maintaining 100% backward compatibility for callers (`SettingsUI.cs`, `ControlsPanelController.cs`).
  - Scanned all 49 `.cs` files in `Star Vanguard/Assets/Scripts/`: 0 files reference `StarVanguard.UI`, `UIPanelRouter`, or `UIPanelId`.

- **Observations in `UIPanelRouter.cs`**:
  - Subscribes to `UIManager` static events and `GameManager.OnGameStateChanged` in `OnEnable()`.
  - Unsubscribes unconditionally in `OnDisable()`, satisfying AGENTS.md Rule 4.
  - Event handlers directly execute real UI operations:
    - `HandleShowSettings()` => `Push(UIPanelId.Settings)`
    - `HandleHideSettings()` => checks `Current == UIPanelId.Settings` then calls `Back()`
    - `HandleShowControls()` => `Push(UIPanelId.Controls)`
    - `HandleHideControls()` => checks `Current == UIPanelId.Controls` then calls `Back()`
    - `HandleShowAudioSettings()` => `Push(UIPanelId.Settings)`
    - `HandleHideSubPanels()` => conditionally rolls back sub-panels via `Back()`
    - `HandleHideAll()` => calls `HideAll()`
    - `HandleGameStateChanged()` => routes state transitions to `UIPanelId.Home`, `Pause`, `GameOver`, or `HideAll()`
  - Panels are managed via an explicit navigation stack (`m_Stack`), CanvasGroup alpha fades (`FadeTo` coroutine), and `ApplyVisibility`.
